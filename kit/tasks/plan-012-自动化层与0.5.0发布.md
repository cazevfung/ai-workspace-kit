## 任务

### 一、建工作树、绑尝试

`git worktree add .worktrees/AWK-109 -b ticket/AWK-109 master`；用宿主 `get_current_session_id` 取到的标识原样写进 `bind_session`（attempt 以 `get_ticket` 的 `current_attempt` 为准）。

证据：`git worktree list` 输出里出现 `.worktrees/AWK-109 ... [ticket/AWK-109]`；`get_ticket` 回执里 `state` 是 `running`、当次 attempt 的 `session_id` 等于本会话标识，退出码 0。

### 二、两份调度正文模板

把本机在跑的两条调度的正文取下来（`cindy_scheduler` 的 `schedule_list` 读 prompt），逐段抹掉本机绑定物：`targetSessionId`、任何 36 位会话 / 调度 id、`AppData\Roaming\Cindy\...db` 路径、`deepseek-*` 模型与 `xd` provider、`D:/cindy-harmony-app` 这类别的项目的根。工作区路径统一写成模板占位（双花括号变量），保留判据段落（四类要看的、粗筛前移、红线）。

证据：`grep -rnE "[0-9a-f]{8}-[0-9a-f]{4}|cindy-[a-z0-9]+\.db|deepseek|provider" kit/automation/` 期望无输出、退出码 1；`ls kit/automation/*.md` 期望列出两份模板。

### 三、`kit/tools/schedule_plan.py`

参数：`--workspace <路径>`（必填）、`--json`、`--timezone`（缺省 `Asia/Shanghai`）、`--only queue|dispatch`。输出两条调度的完整 `schedule_create` 参数：队列值守 `cronExpr` 为 `0,30 * * * *`，派单器为 `*/10 * * * *`，两条都 `silentWhenIdle: true`；派单器的 `preRunHook.command` 指向 `<工作区>/tools/next_action.py`（退出码 0 放行 / 2 跳过 / 其它 fail-closed 直接沿用，不再包一层脚本），队列值守不设闸门并在文档里写明理由。

证据：`python tools/schedule_plan.py --workspace D:/tmp/ws --json` 退出码 0，输出两条调度，每条带 `name` / `cronExpr` / `prompt`，且 prompt 里出现 `D:/tmp/ws`。

### 四、用例（先红后绿）

`kit/tools/test_schedule_plan.py`：缺模板报错、工作区参数必填与绝对路径校验、两条调度的 cron 与 `silentWhenIdle`、`preRunHook` 指向 `next_action.py` 且命令里不含别的脚本、模板里没有占位残留（全部替换）、输出里没有任何本机绑定物（UUID / `cindy-*.db` / 模型名 / provider）、脚本不调用 `schedule_create`（源码里断言），以及 `--only` 与 `--json` 两条分支。

证据：改实现之前跑 `python -m unittest tools.test_schedule_plan -v`（在 `kit/` 下）期望 `FAILED`、`ModuleNotFoundError` 或断言失败；实现之后 `python tools/run_tests.py` 汇总行合计从 932 往上，末行 `结果：全部通过`。

### 五、文档：怎么在自己环境里建这条调度

`kit/docs/无人值守派单.md` 新增一节，写清：两条调度各多久跑一次（30 分钟 / 10 分钟）、`preRunHook` 直接跑 `next_action.py` 并把它的退出码当成「跑不跑」的判据（0 跑、2 跳过、1 fail-closed 且要人看）、`schedule_plan.py` 只打印参数、真建调度由人带着 agent 调 `schedule_create`、离开 Cindy 用系统 cron 加同一个退出码替代（Linux cron / Windows 计划任务各给一行）；队列值守为什么没有闸门。README 与 README.en 各加「自动化：无人值守跑起来」一节，指向 `kit/docs/无人值守派单.md` 与 `tools/schedule_plan.py`。

证据：`grep -n "schedule_create" kit/docs/无人值守派单.md` 期望有输出；`grep -n "无人值守\|schedule_plan" README.md` 期望有输出且命中新增那一节；`python tools/doc_gate.py tasks/plan-012-自动化层与0.5.0发布.md` 退出码 0。
