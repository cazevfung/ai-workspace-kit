### 任务 2：让 `node --test panel/app/test` 真的能跑

本机 node v24.14.0 把目录形参当模块解析（`Cannot find module ...\\test`），而工单 C4 要求这条命令退出 0、七个测试文件都跑到。做法是给目录一个解析目标，不碰任何一个测试用例：

- 新增 `panel/app/run-tests.mjs`：逐条 `import` 七个 `*.test.mjs`（顺序固定，便于对照）；
- 新增 `panel/app/test/package.json`：`{"private": true, "type": "module", "main": "../run-tests.mjs"}`，让目录解析落到那个入口上。

选这个位置的理由：`run-tests.mjs` 放在 `app/` 而不是 `test/`，`node --test` 的默认发现规则不会把 `test/` 目录里多出来的文件当成第八个测试文件，所以 `cd panel/app && npm test` 仍然只跑七个文件、不打双份。`panel/README.md` 写清两个跑法与这条理由。

**验证**：`node --test panel/app/test` 期望退出 0、汇总 `tests 77 · fail 0`；`cd panel/app && npm test` 期望同样 77 项、不是 154 项（后者说明入口被当成第八个文件重复跑了）。
