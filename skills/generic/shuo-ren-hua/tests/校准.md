# 文风校准：拿真实官方文案对照

两份样本来自飞书（`samples/梦光影前瞻.md`、`samples/冰雪季公告.md`），是心动小镇已经发出去的稿子。把自己改的稿子跟它们逐项对比，差在哪很清楚。

## 逐项对照

| 维度 | 真实官方文案 | 我的改写稿 |
|---|---|---|
| 具体物 | 幕布、留声机、萨克斯、野餐毯、爆米花、蒲公英、导演帽章鱼、场记板蜜蜂、冰鞋、荧光棒、咖啡伞 | 几乎没有。全篇是"节奏""体验""门槛""差异"这类词 |
| 时间点 | 3月21日-5月1日（共6周）、1月31日6:00、2月7日6:00后、每晚19:00-21:00 | 十篇里一个具体时间都没有 |
| 称呼 | 发展家、友友、ta | "你""玩家""团队"，泛称 |
| 语气后缀 | 啦、哦、吧、~、"多囤一些""来一段即兴演奏吧" | 干净得像说明书 |
| 句长 | 60 字铺陈，接 8 字短句（"小镇的街角亮起了一面白色幕布……" → "放映春夜物语，描绘幻影时光。"） | 15–25 字，均匀 |
| 段落功能 | 画面 → 信息 → 画面，首尾都是画面 | 判断 → 论证 → 判断，全是观点 |

## 两处我改错了

旧 skill 把这两个当成 AI 标记，一律删。看真实文案，是我误杀。

**破折号。** 真实文案里它做同位语补充，很自然：

> 幕布——你的私人露天放映厅
> 趁庆典期间多囤一些——庆典结束后拼图保留，但采集点会移除哦~

要删的是"揭晓式破折号"（答案其实很简单——专注），不是这一类。

**"当……"排比。** 真实文案用它铺画面：

> 当夕阳沉入城郊湖面，当蒲公英乘着晚风飘向远方——小镇的街角亮起了一面白色幕布

我按翻译腔规则把"当…时"删掉，结果画面就没了。翻译腔的"当…时"是英文 When 从句，句子重心在后半句；这里是排比铺陈，重心在画面本身。

**判断办法：删掉之后画面少不少。** 少了，说明它是修辞，留；不少，说明它只是语法拐杖，删。

## 官方文案的四条硬特征

1. **每段至少有一个看得见的东西**：一件家具、一个 NPC、一种作物、一个时间点。
2. **玩家能被叫住**：发展家、友友，不是"用户"。
3. **句子按画面走，不按逻辑走**：先给场景，再给信息。
4. **允许语气**：啦、哦、吧、~、emoji 章节符。公文语体不需要，游戏文案需要。

## 内部审稿标准（从冰雪季公告的批注里抄的）

这几条比任何规则都硬，因为是真编辑写的：

- 两件事不要混在一句里说，以免让人以为有因果关系
- 不要把非正式说法暴露给玩家
- 不要用已有其他定义的游戏内术语
- 前后指的不是同一个东西，就不要混在一起说

这几条正好是我 28 条规则里没有的：**我一直在管"像不像人"，真实编辑在管"会不会被读错"**。
