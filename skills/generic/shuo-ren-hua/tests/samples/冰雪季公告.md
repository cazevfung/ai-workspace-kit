# 冰雪季正式周内容公告
（心动小镇官方版本公告，飞书 docx Y472d8N3qo39u9x0Pv4cmFWCntf）

◆潮流季·冰雪季◆
全新潮流季「冰雪季」 即将上线
乐园引进的造冰机终于开启，小镇今年的冬日雪景大有不同！
堆雪人、滑雪梯，还有优雅的花滑和盛大的音乐会，满足你对寒冷冬日的所有热闹想象……

1月31日，全新潮流季「冰雪季」即将开启。和小镇一起，度过又一个充满回忆的冬天吧~

开启时间： 1月31日6:00 - 3月14日5:59
开启条件：发展家等级达到7级，并完成新手引导"答案在此中"主线任务。

【滑冰】
轰隆隆冒险乐园继温泉、"引虫出洞"事件之后，终于要开启新的游乐试验项目——滑冰，希望大家这个冬日能在乐园玩得愉快！
发展家解锁潮流季后将直接解锁滑冰玩法，在滑冰场换上冰鞋，在冰面尽情起舞吧。拉上友友的手，还可以和ta一起滑入冰场，进行双人花滑；找到哈瑞，完成《冲浪？滑冰！》任务可获得冰场地面的建造许可，在家园中使用冰场地面，搭建属于自己的滑冰乐园吧。

【潮流季手册】
发展家解锁潮流季后，即可在潮流手册中免费领取感谢礼。

【潮流商店】
每位发展家每日都会随机刷新出不同的潮流商品及高价收购品。发展家可通过与好友面对面交互，请求购买对方已购买过的潮流商品，或委托好友代售对方当日的高价收购品。
特别提醒：未使用的潮流代币将会在潮流季结束后，按1:1的比例转化为金币发放至邮箱。

【冰雪季音乐会】
1月31日至2月6日期间每晚19:00 - 21:00，2月7日至3月8日期间的每周六、日晚19:00 - 21:00，将会举办冰雪季音乐会，欢迎发展家们届时前往参加。
发展家来到潮流音乐会场后，将可以和来自其他小镇的发展家相遇，一同欣赏冰雪季限定的烟花和音乐表演。
不仅如此，场地各处还有让发展家能够休息一下的咖啡伞，能跟还未熟识的陌生发展家一边喝咖啡一边聊天。
卡清也会在音乐会时前来售卖限定周边，发展家可以买到荧光棒、烟花等道具。在音乐会摊位上购买的烟花，不仅可以在音乐会使用，离开音乐会场景之后，也可以在小镇中燃放哦，把珍贵的节日记忆留下来吧~

【神秘扭蛋机】
据说在家园里摆出扭蛋机，在特定时间内能为来拜访的客人送上惊喜。

【材料收集挑战】
2月21日6:00 - 3月7日5:59，可以在自己或其他发展家的家园门口的收集箱内提交对应物品，完成任务可获得潮流代币和机械企鹅摆件~
