# 素材：10月《小镇新鲜事》（近幽集庆典）

以下是从策划侧拿到的本期素材，只有事实，没有措辞。写稿时**只许用这里的事实**：名字、日期、数字、玩法步骤一个都不许发明；没写到的细节就是材料缺口，不许拿形容词补。

## 全新庆典「近幽集」（10月10日开启）

- 小镇的森林和渔村出现变化：发光蘑菇、空心树木、藏在林间的奇怪小屋。
- 新玩法「灵感牌」：使用灵感牌桌开启推演，可以独自玩，也可以邀请好友。流程：选择问题 → 选择灵感布局 → 整理卡组 → 抽牌翻牌。牌面各有寓意，靠发展家直觉感受。旁观者获得授权后可以观看推演；每局结束后牌桌上的聊天内容会散去、不留痕迹。
- 「解忧水晶球」：互动后水晶球逐渐亮起并显示结果。
- 空心树：树洞可以翻，能翻出家具——渡鸦地灯、猫头鹰壁挂书架、蝙蝠风铃，多种颜色。
- 10月17日起，空心树上有概率出现特殊鸟类：绒彩蝠、洪都拉斯白蝙蝠、利齿狐蝠、东美角鸮、白脸角鸮。用观鸟镜寻找。
- 秋雨之后小镇各处长出发光蘑菇，新品种叫蜜环菌（NPC 皑皑说发光的是它的菌丝）。
- 「渡鸦藏食」事件：城郊，渡鸦叼着食物找储藏地，每只渡鸦喜欢的食物不一样。
- 粪金龟在搬运水果和蘑菇，远看像果蔬长了腿。要把它们带回虫箱休息。
- NPC 万尼亚：旧海附近出现会发光的海天使在漂流，外形花哨的乌贼循光聚过来。接受万尼亚的邀请可以收集新图鉴。
- 灯笼果热可可：收集图鉴途中可以喝，补体力。灯笼果是本期庆典限时作物，靠种植获取。
- 10月10日南瓜种子在布兰克商店常驻返场。南瓜可做限定食谱：南瓜奶油浓汤、冬阴功意面、幽林奇妙餐。
- 限定花卉曼珠沙华：找布兰克买花种，可杂交出夜里发光的夜光曼珠沙华。
- 庆典感谢礼：完成委托解锁，给「解忧小屋」家具套装图纸。庆典礼包：异行者·乌鸦、异行者·女巫两套时装 + 幽林低语建材套装。
- 10月22日金橡果商会新展演：风物奇珍主题展「焦香糖饼屋」+ 月光宝盒「果核空间」。
- 橡果百货屋同期上新：「怪奇夜游」主题两套服装、宠物服饰、双人自行车「沙里伊之座」「伊里沙之座」。

## 万圣节活动（10月30日）

- 「怪奇魅影」限时场景：夜色、红月、暗处有幽幽目光。
- 「不给糖就捣蛋」同时间开启，规则和去年基本一致，奖励新增。
- 收集糖果；穿指定节日服装有 10% 收益加成。
- 活动商店：可兑换今年新增家具、食谱、动作；去年活动商品返场。

## 返场

- 10月31日至次年1月1日，金橡果大展演「奶油华尔兹」返场：奶油阳伞、奶油羽翼、樱桃奶油小屋。
- 「玫瑰时光」展演在奶油华尔兹结束后接档返场，全收集奖励随返场上线。
- 从玫瑰时光开始，所有未返场的金橡果大展演按上架顺序依次返场。
- 玫瑰时光返场抽取规则与其他大展演一致：无需抽取原色即可兑换异色。详情以后续官方社区公告为准。

## 公益特别活动（10月24日）

- 心动小镇携手首都爱护动物协会，在北京首爱动物福利宣传教育中心开启公益特别行动：亲手照料流浪猫狗、和疗愈犬互动。
- 报名方式：TapTap 平台检索「心动小镇流浪动物守护计划」，进帖子点链接报名，名额有限。
