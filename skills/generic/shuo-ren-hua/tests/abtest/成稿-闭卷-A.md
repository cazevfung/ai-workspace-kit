# 小镇新鲜事脚本-11月（小马宝莉联动 + 舞谱创作）

- 体裁：单人口播，喵喵主持
- 参照样本：小镇新鲜事脚本-0919（活动 + 你说喵答 + 版本更新混合结构）

## 台词

L1 [开场] 巴布！发展家们好呀～秋去冬来，小镇的空气里多了一点凉意，但新鲜事可是一点都不少！
L2 [开场] 这一期内容满满：小马宝莉第二期联动即将开启，全新舞谱创作玩法上线，还有作品摊位、邮局故事活动和一大波功能优化~
L3 [开场] 当然，大家关心的你说喵答也不会缺席！发展家们坐稳喽，我们这就开始！

L4 [小马宝莉联动] 先来讲讲这次联动的故事：异界的暴风雪席卷大地，和谐之树渐渐失去了生机，小马们把它带到了鲸鱼岛。
L5 [小马宝莉联动] 而拯救和谐之树的关键，就是代表无私、包容与爱的「友谊之火」——宇宙公主和月亮公主也会登场哦！
L6 [小马宝莉联动] 11月14日，预热活动「小马宝莉 友谊之旅」率先开启：每日登录点亮拼图就能领取奖励，集齐拼图还可以获得「星彩礼花炮」！
L7 [小马宝莉联动] 11月21日，联动正式上线！在主题活动「小马宝莉 和谐焕生」中，发展家要收集友谊火种。
L8 [小马宝莉联动] 在活动页面追踪彩虹滑梯，前往和谐之树传递火种，就能净化被风魔侵蚀的和谐之树，领取奖励啦~
L9 [小马宝莉联动] 新展演也来啦！「双曜小马」系列风物奇珍主题展登场，里面有宇宙公主与月亮公主的主题服装和联动载具。
L10 [小马宝莉联动] 第一期「虹能小马」系列风物奇珍主题展也会同期返场，抽取和收集进度全部继承！
L11 [小马宝莉联动] 集齐两款「双曜小马」系列载具，可以领取带特效的可交互家具「小马魔法留影机」。
L12 [小马宝莉联动] 集齐六款「虹能小马」系列载具的发展家，还能领取拥有镭射流光效果的限定载具「和谐之元」！
L13 [小马宝莉联动] 联动开启后，橡果百货屋同期推出「闪耀小马」系列主题服装，有雾鬃和美照菲尼莎两款哦~
L14 [小马宝莉联动] 联动限定家居展参选「小马彩虹乐园」系列家具同步上线；「天马行空」主题活动也准备好啦，在同款主题跑酷关卡里完成打卡任务，就能获得限定奖励！

L15 [舞谱创作玩法] 说完了小马们的故事，再来看一个喵喵期待已久的新玩法——舞谱创作！11月12日更新后，发展家达到18级就能解锁。
L16 [舞谱创作玩法] 想开始创作很简单：把「舞蹈练习镜」放置在家园中，通过它就能进入舞蹈创作。
L17 [舞谱创作玩法] 动作、面部表情、乐曲全都可以编辑，最长能制作5分钟的完整舞蹈！
L18 [舞谱创作玩法] 进入创作界面，先给舞蹈起个名字。界面里有一条时间轴，把喜欢的动作添加进动作轨道就好。
L19 [舞谱创作玩法] 没有灵感也不怕，可以先用推荐的起始动作开场；所有动作都支持编辑倍速、调整长度，时间轴也能缩放。
L20 [舞谱创作玩法] 光动身体还不够，表情才是灵魂！把表情轨道挪到对应的时间点，就能给舞蹈加入面部表情。
L21 [舞谱创作玩法] 乐曲轨道里，既可以选官方乐曲，也可以用自己创作的音乐。
L22 [舞谱创作玩法] 编舞过程中随时按下浏览键，镜子里的角色就会伴着音乐，实时跳出整段编好的内容~
L23 [舞谱创作玩法] 编好了想出版？消耗1张「舞蹈出版许可券」，选好舞谱封面，等审核通过，你的舞蹈就正式成为可以在小镇流通的舞谱啦！
L24 [舞谱创作玩法] 出版后的舞谱会出现在表情动作栏里，像使用动作一样选中它——起舞！开始跳舞时，舞谱会被轻轻抛到身前，路过的发展家可以凑近翻看舞谱详情、留下表情反馈。
L25 [舞谱创作玩法] 作品还会出现在书店区域的舞谱商店里，被全镇发展家看到、试阅、购买哦！
L26 [舞谱创作玩法] 还没集齐舞谱里的所有动作也没关系，可以先用占位动作跳起来；慢慢收集齐后，舞蹈会越来越接近最初的编排。
L27 [舞谱创作玩法] 对了，还有一批全新单人动作上线，前往安妮的友爱商店就能获取哦~

L28 [梦想与摊位] 新梦想也安排上了！「舞蹈家」梦想登场：创作舞蹈、出版舞谱、出售舞谱都能提升梦想等级，等级奖励里有舞蹈出版许可券、舞谱封面，还有更多配色的舞蹈练习镜。
L29 [梦想与摊位] 另一位新朋友是「收藏家」梦想——它要配合全新的作品摊位玩法一起玩。
L30 [梦想与摊位] 更新后，发展家可以在小镇里支起小摊位，把已经公开出版的各类作品上架出售，书籍、唱片和舞谱都支持！
L31 [梦想与摊位] 摆摊时，可以挑选要展示的作品、编辑摊位名称和简介，还能给作品排序。
L32 [梦想与摊位] 摊位分小型和中型：小型能容纳20件作品，中型能容纳30件；每位发展家同时最多摆放1个摊位。
L33 [梦想与摊位] 摊位可以摆在自己家园里，也可以投掷到小镇中，让更多发展家逛到~
L34 [梦想与摊位] 逛摊的发展家可以自由预览：书籍能完整阅读，唱片能完整播放，舞谱能完整观看动作演示，遇到喜欢的直接订购带回家！
L35 [梦想与摊位] 摆摊进度提升，还能增加收藏家梦想的成长值，从「摆摊人」一路成长为「主理人」，一路上都有对应奖励！

L36 [策展派对] 说到逛摊位，还有一个更热闹的玩法——策展派对！
L37 [策展派对] 派对开启后，家园里公开摆放的作品会对外开放，书籍、唱片、舞谱都能免费预览，看到喜欢的还能现场订购。
L38 [策展派对] 看完别忘了用表情向摊主送上反馈哦~

L39 [邮局] 接下来，轮到小镇邮局登场啦！邮局开始收件喽~
L40 [邮局] 把一次偶遇、一段冒险，或者一个只有你知道的小故事写成信，投进邮局，就有机会被更多发展家读到。
L41 [邮局] 信件会经过投稿、展示、成功发布等阶段；投稿符合要求并通过审核，就能获得「邮筒睡觉喵夜灯」家具摆件和「叙梦者」称号！

L42 [你说喵答·过场] 介绍完近期活动，又到了发展家们关心的你说喵答环节~这一次，喵喵照例带着大家的提问，找工程师们打听到了不少最新情报，来看看吧！
L43 [Q1 派对节常驻] 提问：派对节能不能常驻呀？
L44 [Q1 派对节常驻] 目前派对节是小镇里的「定期惊喜」，会在每次潮流季和庆典的中后期上线——这样安排，是想让发展家体验完新内容之后，再用派对节转换一下心情。未来随着自由创作的内容越来越多，派对会带来更多新模式哦！
L45 [Q2 生日活动] 提问：小镇能上线生日活动吗？
L46 [Q2 生日活动] 可以的！11月12日更新后，生日活动正式上线：在名片里写下自己的生日，生日周小镇居民就会送上祝福。要注意哦，生日设置生效后，要365天才能再次修改。
L47 [Q2 生日活动] 友友过生日也别错过：去卡清的杂货店挑生日蛋糕和蜡烛，去波叔的家居店挑数字气球，为TA亲手制作并送上蛋糕与祝福~还有生日烟花、明信片、回忆手帐等活动，生日周乘坐热气球还可能有特殊际遇呢！
L48 [Q3 仓库与置顶] 提问：仓库库存能不能增加？常用物品可以加置顶吗？
L49 [Q3 仓库与置顶] 11月12日更新后，卡清的杂货店会投放一批「仓库扩展券」，之后也会定期补充；工程师们还在开发优化仓库功能和页签分类，让高频物品更好找~
L50 [Q4 盖被子] 提问：睡觉的时候能不能盖被子？
L51 [Q4 盖被子] 这个被大家讨论了好久的小愿望，工程师一直记在心上——盖被子功能已经在开发中啦，还需要一些时间打磨，有新进度喵喵会第一时间同步！
L52 [Q5 新地图与潮流季] 提问：以后还会有新地图、新庆典和潮流季玩法吗？
L53 [Q5 新地图与潮流季] 会的！12月冬季将至，全新潮流季再过几周就要开启啦。上一个潮流季小镇里出现了海底区域，这一次也有值得期待的新玩法~具体的实机玩法，还请期待12月初的版本前瞻特别节目！

L54 [更多更新与优化·过场] 细心的发展家可能已经发现，上面不少内容都会在11月12日更新时上线。接下来，喵喵就带大家快速看看这次版本里的更多内容吧~
L55 [更多更新与优化] 研究所又上新啦~新增多种过山车轨道组件：翻转轨道、倾斜回旋轨道、侧回环轨道、扭转大回环轨道，还有不同尺寸的翻转缓坡、翻转陡坡和香蕉弯。
L56 [更多更新与优化] 波叔的家居店上架了工具间主题家具：轮胎、油漆桶、人字梯、工具栏，动手党可以逛起来啦~
L57 [更多更新与优化] 留声机现在可以像画板一样投掷摆放到大世界，不同发展家的留声机还能同时录制演奏者的演奏；新乐器管风琴也来啦~
L58 [更多更新与优化] 友情手帐新增星标好友功能：星标好友会显示在好友列表最上方，无论是否在线，都能第一时间定位到TA。
L59 [更多更新与优化] 配方也更贴心了：查看食谱、工匠配方和建材图纸时，可以提前看到制作或建造所需的材料；点击材料图标，还能查看简要信息。
L60 [更多更新与优化] 化妆镜里可以保存五官和发型预设，造型预设和服装预设分开保存；在小镇中长按角色，就能打开预设界面切换造型~
L61 [更多更新与优化] 最后是举报优化：举报违规行为后，如果审核确认并执行处罚，发展家会收到处理反馈邮件，告知处罚对象、违规类型和处罚方式；未受理、审核不成立或未处罚的，则不会发送反馈邮件哦。

L62 [收尾] 以上就是本期小镇新鲜事的全部内容啦！联动、舞谱、摊位、邮局……11月的小镇可太忙了，发展家们记得定好闹钟，准时来小镇参与哦~
L63 [收尾] 喵喵要先去把舞蹈练习镜搬回家园，编一支属于喵喵的舞啦——下次在小镇里看到一只起舞的喵，记得凑近翻翻我的舞谱哦！
