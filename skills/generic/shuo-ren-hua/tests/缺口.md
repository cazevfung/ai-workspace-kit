# 材料缺口

这 10 篇改到第 15 轮，语言层能做的都做了。剩下的"还不太像人写的"，是内容层的问题：每篇都是观点和判断，几乎没有一个具体的事件、人、时间、数字。

按 skill 第二步的要求，这些缺口列出来交给作者，不要用形容词去填。

| 篇 | 缺口 |
|---|---|
| 01 | 说"改比写费劲"，没有具体模块、改了什么、花了多久。补一个真实例子。 |
| 02 | 说"多数团队停在评估"，没有对象。补一个团队、一个卡住的环节、卡了多久。 |
| 03 | 六个模块里没有一个是真实需求。补一个跑过这套流程的案例。 |
| 04 | 三处更新都只有形容词（更舒服、不那么僵、不至于卡住）。补玩家能看见的具体变化。 |
| 05 | 全篇没有具体价格、时长、地点。补一个"我"的真实下午：几点上线、做了什么、花了多少。 |
| 06 | 活动时长、奖励数量、"明显增加"都还是模糊的。补具体天数、具体奖励。 |
| 07 | "用错的方式证明自己"没有一个例子。补一个具体场景：什么时候、对谁、怎么证明的。 |
| 08 | 只有表弟一个人名，没有他的具体动作。补一个细节：面包店叫什么、第一天发生了什么。 |
| 09 | 四个字段没有任何一次真实使用。补一次卡住的项目，哪一格救了场。 |
| 10 | "用户的每一次点击"是空的。补一个真实数字或一个用户故事。 |
