# UI 设计

一套已经验收过的设计语言，用来回答每次做界面都要重新决定的那几件事：间距用哪一档、圆角多大、深浅两套色怎么取、图标从哪来、动效多快。数值全部来自鸿蒙版 Cindy 的设计系统，本技能只做归纳与可执行化，不新造色值，也不新造档位。

## 什么时候用、什么时候不用

| 情况 | 归谁 |
| --- | --- |
| 要做一个页面 / 一个面板 / 一个列表，得定色、间距、圆角、字阶、主题 | 这里 |
| 要先把设计流程走完（定方向、评审打分、抓 AI 味） | 本技能管数值，流程与评审走 `impeccable` |
| 要顺手把界面配上图标、加动效、加按压反馈 | 这里 |
| 手上有一个现成界面，要判断它哪里不像样、哪里太挤、点了没反应 | 这里 |
| 只是把一段中文改得像人话 | `shuo-ren-hua` |
| 写需求、定验收条件、判断这功能该不该做 | `prd-authoring` |
| 做 Cindy 插件（ghost）本身的开发与发布 | `cindy-plugin-creator` |
| 出海报、通知卡、四字方图这类静态图 | `notice-cards` / `square4` |

## 五步工作流

| 步 | 做什么 | 看哪份 |
| --- | --- | --- |
| 一，定取向 | 先定这一屏是排版主导还是色彩主导、松一档还是密一档、留白分层还是加框分层。默认就是「排版主导 + 松一档 + 留白优先」，不默认的话每页各写一套 | `references/design-language.md` §1 |
| 二，取 token | 颜色只写语义名，间距、圆角、字阶、时长只从档位里取；两套主题各一份值，键集合一致 | `assets/tokens.css`，说明在 `references/design-language.md` §2–§5 |
| 三，定形状与图标 | 先定这一页用哪两三种圆角，再按位取图标尺寸；图标只从 Lucide 取，描边统一 1.75 | `references/icons.md` |
| 四，定动效 | 按「这个元素多常用、它为什么动」决定动不动；动的只用参数表里的时长与曲线，参数从 `@animate-ui/react/utils/motion` 取 | `references/motion.md` |
| 五，过闸门 | 跑检查脚本与品质判据表，红的地方改到绿，不接受「整体感觉还行」 | `references/quality-gate.md`，`references/stacks.md` 看落地差异 |

## 硬规矩

每条一句正面做法，后面一句是「看到什么算不合格」。

1. **层次靠字号、字重、留白分**。同一屏字号不超过四档、留白不超过三档。看到「为了有层次把卡片加回描边或投影」就不合格。
2. **所有尺寸成档**。间距 4/8/12/16/24/32，圆角 4/16/20/24/9999，字号 11/12/13/15/16/17/18/20/24，时长 120/150/250/320/900/1100ms。看到 `padding: 10px`、`border-radius: 12px`、`font-size: 14px` 这类档外字面量就不合格。
3. **色值只在一处定义**。页面里只写 `var(--color-*)` 或 Tailwind 主题名。看到页面文件里出现裸 `#RRGGBB`、`rgb(`、`hsl(` 就不合格（`tokens.css` 的 `:root` 与 `:root[data-theme="dark"]` 除外）。
4. **描边只留给浮起来的面**。描边只剩代码块与浮层两处，卡片靠淡底分层、列表靠发丝分隔线。看到列表每一行都画一圈框、或给卡片同时加描边和投影，就不合格。
5. **图标只有一套**。只从 Lucide 取，24 网格、描边 1.75、颜色走 `currentColor`。看到字符图标（`›`、`⋯`、`☰`、`✓`）、emoji 当图标、混进 font-awesome 或 iconfont，就不合格。
6. **可点就有反馈**。按下当场缩放或变色，不等业务结果；就地展开优先于整页跳转。看到「点一下整页跳走」或「按下毫无变化」，就不合格。
7. **动效只解释空间关系**。从底部来的从底部来，时长与曲线都在档上，并且尊重 `prefers-reduced-motion`。看到 `transition: all`、无限旋转、关掉动效后状态就不生效，都不合格。
8. **可读性与可达性是底线**。正文对比度 ≥4.5:1、界面元素 ≥3:1，常规控件热区 ≥44px，键盘能走到并且 `:focus-visible` 看得见。看到 `outline: none` 而没有替代焦点样式、或热区只有 20px，就不合格。

## 交付前闸门

在仓库根跑，两条都必须退出 0：

```bash
python skills/ui-design/scripts/check_ui.py <文件或目录>
python skills/ui-design/scripts/test_check_ui.py
```

第一条会把九类跑偏变成 `文件:行号 [规则名] 说明` 并退出 1；第二条证明每条规则真的能判出红、改对后真的变绿。`scripts/fixtures/bad-page.html` 是故意写坏的现场证据，脚本跑它必须退出 1。目录里的 `fixtures/` 默认跳过（那些样本就是用来红的），要检查某一份就把它当参数直接点名。

判据里那几条脚本量不出来的（层级、留白节奏、玻璃、空态），照 `references/quality-gate.md` 的判据表逐条看，只列不及格项与位置。
